ODAT-SE Documentation#

ODAT-SE is a software framework for inverse problem analysis that combines search algorithms with direct problem solvers. It lets you try multiple search methods within a common workflow for inputs, outputs, and execution.

Choose What You Want To Do#

  • Install It First Check prerequisites, basic execution modes, restart options, and MPI basics.

  • Run a Sample First Follow hands-on examples to understand how each algorithm works in practice.

  • Look Up Input and Output Details See the specifications of input files, output files, algorithms, and solvers.

  • Troubleshoot a Problem Find answers on installation, algorithms, errors, and customization.

Overview#

  • Combine search algorithms and direct problem solvers to solve inverse problems

  • Choose among Bayes, PAMC, replica exchange, grid search, and other methods

  • Extend the framework with custom solvers or external programs

  • Use sample data and templates as a starting point for real applications

Related Resources#

  • Samples and Templates Browse samples for TRHEPD, SXRD, LEED, and XAFS, as well as solver templates.

  • Customization Guide Start here if you want to develop your own algorithms or direct problem solvers.

  • API Reference Browse the specifications of all public APIs generated automatically from docstrings.
