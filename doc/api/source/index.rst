ODAT-SE API Reference
=======================================

This is the API reference of `ODAT-SE <https://github.com/issp-center-dev/ODAT-SE>`_,
generated automatically from the docstrings in the source code.
It covers all public modules, classes, and functions of the ``odatse`` package,
including the solver/algorithm base classes used for customization
(``odatse.solver.SolverBase``, ``odatse.algorithm.AlgorithmBase``),
the ``Runner`` bridge, and the utility layers (``odatse.util.*``, ``odatse.domain.*``, ``odatse.mpi``).

For installation, tutorials, and input/output specifications, see the user manuals:

- `User manual (Japanese) <../ja/index.html>`_
- `User manual (English) <../en/index.html>`_

For a guided introduction to writing custom solvers and algorithms,
see the "Customization" chapter of the user manual.
